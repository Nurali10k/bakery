# Miette Bakery & Café

A responsive bakery and café landing page built with React, Vite, Tailwind CSS 4, and Lucide icons. It includes a hero, featured menu, bakery story, opening hours, location, and a newsletter signup confirmation.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Demo content

The bakery name, menu prices, address, hours, and Unsplash image URLs are sample content. The newsletter form validates an email and shows an on-page confirmation; connect it to an email service to collect subscriptions.
